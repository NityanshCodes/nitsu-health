# Quick Start Guide - NITSU Health\n\n## Prerequisites\n\n- Python 3.9+\n- Node.js 18+\n- Git\n\n## Local Development Setup\n\n### 1. Clone and Setup Environment\n\n`bash\ngit clone <repository>\ncd nitsu-health\n\n# Create Python virtual environment\npython3 -m venv .venv\nsource .venv/bin/activate  # On Windows: .venv\\Scripts\\activate\n\n# Copy env template\ncp backend/.env.example backend/.env\ncp .env.example .env\n\n# Install Python dependencies\ncd backend\npip install -r requirements.txt\ncd ..\n\n# Install Node dependencies\ncd frontend\nnpm install\ncd ..\n`\n\n### 2. Start Backend\n\n`bash\ncd backend\nsource ../.venv/bin/activate\nuvicorn app.main:app --reload\n`\n\nBackend will be available at: `http://localhost:8000`\n\n**Health check:**\n`bash\ncurl http://localhost:8000/health\n# Response: {\"status\": \"running\", \"service\": \"backend\"}\n`\n\n### 3. Start Frontend (in a new terminal)\n\n`bash\ncd frontend\nnpm run dev\n`\n\nFrontend will be available at: `http://localhost:5173`\n\n### 4. Test the App\n\nOpen `http://localhost:5173` in your browser:\n\n1. **Register**: Create a new account\n - Email: test@example.com\n - Username: testuser\n - Password: TestPass123 (must have uppercase, lowercase, digit)\n\n2. **Login**: Use the credentials you just created\n\n3. **Dashboard**: View your health summary\n\n4. **Verify API**: Check backend logs for successful requests\n\n---\n\n## Development Workflow\n\n### Running Tests\n\n`bash\n# Backend tests\ncd backend\nPYTHONPATH=. python -m pytest tests -v\n\n# Expected: 34 passed\n`\n\n### Code Quality\n\n`bash\n# Format Python code\nblack backend/app\n\n# Lint Python code\nflake8 backend/app\n\n# Type check Python\nmypy backend/app\n\n# Format TypeScript/React\ncd frontend\nnpm run lint\n`\n\n### Database\n\n**View database:**\n`bash\nsqlite3 backend/nitsu_health.db\n.tables  # List all tables\nSELECT * FROM users;  # Query users\n.quit  # Exit\n`\n\n**Reset database (development only):**\n`bash\nrm backend/nitsu_health.db\n# Restart backend - it will recreate the database\n`\n\n### Adding a New Feature\n\n1. **Backend**\n `bash\n   # 1. Create a model in app/models/\n   # 2. Create a schema in app/schemas/\n   # 3. Create an API endpoint in app/api/\n   # 4. Add tests in tests/\n   # 5. Run: pytest\n   `\n\n2. **Frontend**\n `bash\n   # 1. Create a component in src/components/\n   # 2. Create a page in src/pages/\n   # 3. Add route in src/App.tsx\n   # 4. Call backend via src/services/api.ts\n   # 5. Run: npm run dev\n   `\n\n---\n\n## Environment Variables\n\n### Backend (.env)\n\n`ini\n# Database\nDATABASE_URL=sqlite:///./nitsu_health.db\n\n# JWT Authentication\nJWT_SECRET_KEY=your-secret-key\nJWT_ALGORITHM=HS256\nACCESS_TOKEN_EXPIRE_MINUTES=60\n\n# AI Provider\nAI_PROVIDER=development  # or \"openai\"\nOPENAI_API_KEY=          # Leave empty for development\nOPENAI_MODEL=gpt-4o-mini\n\n# Environment\nENVIRONMENT=development  # or \"production\"\nDEBUG=true              # false in production\n\n# CORS\nCORS_ORIGINS=http://localhost:5173,http://localhost:4173\n`\n\n### Frontend (.env)\n\nThe frontend automatically uses `http://localhost:8000` as the API URL in development.\nSet `VITE_API_URL` if your backend is on a different host.\n\n**Important:** Never put secret keys in frontend env vars - they're visible to users!\n\n---\n\n## Common Issues\n\n### Backend won't start\n\n**Error:** `ModuleNotFoundError: No module named 'app'`\n\n**Solution:**\n`bash\ncd backend\nPYTHONPATH=. uvicorn app.main:app --reload\n`\n\n### Frontend can't connect to backend\n\n**Error:** `CORS error` in browser console\n\n**Solution:**\n`bash\n# Verify backend is running\ncurl http://localhost:8000/health\n\n# Check CORS_ORIGINS in backend/.env includes localhost:5173\necho $CORS_ORIGINS\n`\n\n### Password validation fails\n\n**Error:** `password must include at least one uppercase letter`\n\n**Solution:** Password must have:\n- At least 8 characters\n- At least one uppercase letter (A-Z)\n- At least one lowercase letter (a-z)\n- At least one number (0-9)\n\nExample: `MyPassword123`\n\n### Database locked\n\n**Error:** `database is locked` or `SQLITE_BUSY`\n\n**Solution:**\n`bash\n# Kill the backend process\n# Or delete and recreate the database\nrm backend/nitsu_health.db\n`\n\n---\n\n## Project Structure\n\n`\nnitsu-health/\n├── backend/\n│   ├── app/\n│   │   ├── api/                  #
