# Frontend Architecture

This frontend is scaffolded for NITSU Health Phase 3. It contains:

- public/ for static assets
- src/app/ for page modules and screens
- src/components/ for reusable UI
- src/services/ for backend API calls
- src/hooks/ for custom React hooks
- src/context/ for global providers
- src/store/ for global state management
- src/styles/ for global styling
- src/types/ for TypeScript model definitions
- src/utils/ for shared helpers
- src/middleware/ for route protection
- tests/ for frontend tests
